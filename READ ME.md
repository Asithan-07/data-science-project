# Bank Customer Churn Prediction

## Project Overview

This project explores bank customer data and uses machine learning to predict whether customers are likely to leave a bank.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-learn

## Project Files

* `churn_prediction.py` — Python source code.
* `output.txt` — Sample execution output.

## Objective

To analyze customer data and build a machine learning model for predicting customer churn.

## How to Run

1. Install Python.
2. Install the required libraries.
3. Run `churn_prediction.py`.

The code and output should be verified before considering the project complete.
